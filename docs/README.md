# Template Factory Documentation

This folder contains maintainer documentation for the archived template
factory. Generated-product documentation lives under `template/docs/`.

## Index

- [template-decisions.md](template-decisions.md) records factory decisions that
  should not become product ADR history.
- [template-offload.md](template-offload.md) records why the template factory
  has been parked as portfolio material.
- [testing.md](testing.md) records archive validation, packed-CLI testing, and
  generated-product smoke expectations.

Historical or in-progress planning notes may live here when they are useful for
factory maintenance, but stable generated-product rules belong under
`template/docs/`.
